# The demo course

<!-- EXIT ZERO — DO NOT MODIFY THIS SECTION -->
This repo is a student project in a software engineering course. All course workflow is handled by the `.exit0/e0` cli tool. 

Before you answer the any student's message, run `.exit0/e0 status`. It tells you where the student is and what comes next. If `.exit0/e0` is missing, that command will fail. Then read `.exit0/skills/setup-and-update/SKILL.md` and follow it.

Once `e0` works, read `.exit0/skills/learning/SKILL.md`. It tells you how to help the student with their course work.

When you manage the course process using `e0`, you don't need to narrate your own process. Just run the command and tell the student what it means for them.
